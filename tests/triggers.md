# 触发测试句

每个 skill 写 5 句应该触发它的话、3 句不该触发它的话。改了 description 之后用这些句子检查触发是否准确。

检查方法：把本机所有 skill 的 name 和 description 汇总给一个新开的 Agent，让它只根据 description 判断每句话会用哪个 skill（或者不用 skill），不执行任何 skill。应触发的句子要选中对应 skill，不应触发的句子不能选中它。

## ak-domain-learner

应触发：

1. 我想系统学一下量化交易，完全零基础
2. 帮我从零入门 Kubernetes
3. 给我讲讲保险这个行业，我想能跟内行聊
4. 继续学 Rust，接着上次
5. I want to learn color grading from zero

不应触发：

1. Docker 是什么？
2. 帮我读一下这个 PDF 并总结
3. 调研一下 2026 年的 AI Agent 框架

## ak-weekly-review

应触发：

1. 开始周复盘
2. 帮我复盘一下这周
3. 本周复盘，目标我贴在下面
4. weekly review
5. 这周过得有点乱，复盘这周吧

不应触发：

1. 帮我复盘一下这个项目上线出的事故
2. 做一下九月的月度复盘
3. 看看我今天这篇日记写得怎么样

## ak-sprout

应触发：

1. 给这条笔记发芽
2. 这段话能发芽吗：既往不恋，当下不杂，未来不迎
3. 来点远方的回响
4. 帮我给刚写的那条笔记出个发芽报告
5. 这个想法挺有意思，发个芽看看

不应触发：

1. 找一下库里和 LSP 相关的笔记
2. 帮我总结一下这篇文章
3. 这条笔记的标签打得对吗

## ak-image-organize

应触发：

1. 整理一下根目录那堆图
2. 这些截图都没名字，帮我改名
3. 归档附件
4. Obsidian 里的 Pasted image 太多了，处理一下
5. 图片太乱了，整理图片

不应触发：

1. 把这张图压缩到 200KB 以内
2. 帮我生成一张封面图
3. 整理一下手机相册里的照片
