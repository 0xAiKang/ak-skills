# 认知地图文档骨架

开始学习时，按下面的骨架新建认知文档。第 0 步的回答写进 Metadata，第 1 步的大纲写进章节索引，之后每章按同一结构往下追加。

```markdown
# {领域名} · 认知地图

## Metadata（第 0 步答案）

- **学习者背景（来自项目说明文件 / 对话）**：[职业 / 长期方向]
- **相邻领域锚点**：[Q1 答案]
- **接触深度**：[Q2 答案]
- **目标深度**：[Q3 答案]
- **开始时间**：YYYY-MM-DD

## 章节索引

| # | 章节名             | 状态  |
|---|--------------------|-------|
| 1 | 全景叙事 + 术语速查 | ⏳   |
| 2 | ...                | ⏳   |
| ... | ...              | ...   |

---

## 第 1 章：全景叙事 + 术语速查

### 核心概念
[3a 内容]

### 视角扩展
[3b 内容]

### 真实例子
[3c 内容]

  - 用户答案：...
  - 核心要点覆盖情况：...
  - 最终判定：✅
- Q2: ...

---

## 第 2 章：...
（同上结构）
```
